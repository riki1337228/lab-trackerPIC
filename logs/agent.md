# Запис про кодинговий агент

| Параметр | Значення |
|---|---|
| Назва | Claude Code (Anthropic) |
| Модель | Claude Opus 5.5 (`claude-opus-5-5`) |
| Клас інструменту | Агентний кодинговий асистент (agentic coding tool) на основі LLM; працює автономно в циклі «план → дія → перевірка» |
| Інтерфейс | Розширення Claude Code для VS Code (також доступний як CLI у терміналі) |
| Спосіб доступу до репозиторію | Прямий доступ до локальної робочої копії `lab-tracker/` через файлову систему та оболонку (PowerShell / Git Bash) на машині студента. Віддалений репозиторій агент не змінює без окремого дозволу |
| Режим дозволів | Кожна дія, що змінює файли або виконує команди, підтверджується користувачем (або дозволена налаштуваннями сесії) |

## Операції, які агент може виконувати

- **Читання**: перегляд файлів, пошук за шаблоном імен (glob) і вмістом (grep), аналіз структури проєкту.
- **Запис**: створення нових файлів, точкове редагування наявних (заміна фрагмента).
- **Команди оболонки**: запуск `git`, `python`, тестів та інших CLI-утиліт.
- **Git**: `status`, `diff`, `add`, `commit`, `branch`, `switch`, `merge`, `log`. Операції `push`, переписування історії та примусові дії — лише за явною вказівкою людини.

## Обмеження та правила використання

- Агент не має доступу до мережевих сервісів поза дозволеними інструментами.
- Усі зміни агента переглядаються людиною через `git diff` до коміту/злиття.
- Коміти, у яких зміни згенеровано агентом, позначаються трейлером
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` та міткою `[agent]`
  у заголовку (див. [docs/git-workflow.md](../docs/git-workflow.md)).
