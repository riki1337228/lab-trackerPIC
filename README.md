# Lab Tracker

Індивідуальний проєкт практикуму з Specification-Driven Development (SDD).
Система обліку виконання лабораторних робіт студентом.

## Структура репозиторію

| Каталог | Вміст |
|---|---|
| `spec/` | Опис задуму, специфікації (SRS), відкриті питання |
| `tests/` | Тести та критерії приймання |
| `src/` | Програмний код |
| `docs/` | Документація проєкту та процесу (модель гілкування, конвенції) |
| `logs/` | Журнали взаємодії з кодинговим агентом, рішення контрольних точок |

Правила роботи з Git: [docs/git-workflow.md](docs/git-workflow.md).
